# MD Base64

> 一个 Obsidian 插件：把当前笔记导出成「图片内联」的单文件 Markdown —— 发给别人、丢进任何 Markdown 阅读器都不缺图。**原笔记一个字都不动。**

[![author](https://img.shields.io/badge/author-Hadesr-blue)](#许可)
[![version](https://img.shields.io/badge/version-1.1.0-green)](#)
[![platform](https://img.shields.io/badge/platform-desktop%20%7C%20mobile-lightgrey)](#)

**零依赖** —— 不用任何第三方库，也不用 Electron 那个已经被移除的 `@electron/remote`。桌面（Windows / macOS / Linux）与移动端（iOS / iPadOS / Android）通用。

## 它解决什么问题

笔记里引用了一堆本地图片，一旦笔记发出去（微信 / 邮件 / 别的编辑器），图片链接全断 —— 因为对方没有你的图库。

这个插件把每张图片转成 `data:image/png;base64,...` **内联进正文**，产出一个**自包含**的 `.md`：单文件带走，图永远在。

---

## 特性

| 能力 | 说明 |
| --- | --- |
| **两种语法都认** | `![[图片.png]]`（wiki 嵌入）**和** `![别名](图片.png)`（标准 markdown） |
| **保留语义** | `![[a.png\|300]]` 的宽度用 `<img width>` 保住；`![alt](a.png "title")` 的别名保留 |
| **幂等** | 已经是 `data:` 的图片自动跳过 → 可反复导出，不会二次膨胀 |
| **进度提示** | 导出时显示"正在内联图片 3/12" |
| **失败清单** | 哪张图没找到会明确列出，而不是静默留个坏链接 |
| **远程图可选内联** | `![x](https://…)` 也能下载内联（走 Obsidian `requestUrl`，绕 CORS） |
| **两种落地方式** | 浏览器下载 / 写入库内指定文件夹（手机也方便） |
| **右下角状态栏按钮** | 点一下就导出 |
| **原笔记不动** | 只读源文件，产物是另存的新文件 |
| **桌面 + 移动** | `isDesktopOnly: false`，手机端同样可用 |

## 和同类插件对比

| 对比项 | Export as Base64 MD | **MD Base64** |
| --- | --- | --- |
| `![[图片.png]]` | ✅ | ✅ |
| `![别名](图片.png)` | ❌ **只读 metadataCache.embeds，一律漏掉** | ✅ |
| `![别名](<路径 含空格.png>)` | ❌ | ✅ |

| **移动端** | ❌ `isDesktopOnly: true` | ✅ **`false`** |
| 找不到的图片 | 静默留坏链接 | ✅ 明确清单 |
| 进度提示 | ❌ | ✅ |
| 远程图片 | ❌ | ✅ 可选内联 |
| **复制到剪贴板** | ❌ | ✅ 额外命令 |

## 安装

### 方式一：手动拷贝（推荐，零依赖）

1. 下载本项目的三个文件：`main.js`、`manifest.json`、`styles.css`
2. 放进你的库：

```
<你的库>/.obsidian/plugins/md-base64/
├── main.js
├── manifest.json
└── styles.css
```

3. 打开 Obsidian → `设置` → `第三方插件` → 刷新 → 启用 **MD Base64**

### 方式二：BRAT（适合手机端 / 自动更新）

1. 先从社区插件市场安装 **BRAT**
2. BRAT 设置 → `Add a beta plugin` → 填入本仓库地址
3. 自动安装并启用

> **iOS / iPadOS 提示**：系统「文件」App 没有"显示隐藏文件"开关，`.obsidian` 是隐藏目录。推荐用 **BRAT**，或用电脑操作。
> **BRAT 注意**：本仓库的插件文件在**根目录**（不在 `dist/` 子目录里）。

## 用法

两种入口：

1. **右下角状态栏按钮「导出 Base64」** —— 点一下导出当前笔记
2. **命令面板** `Ctrl/Cmd + P`
   - `MD Base64: 导出当前笔记为 Base64 MD（图片内联）`
   - `MD Base64: 复制当前笔记（Base64 内联）到剪贴板`（不落盘）

> 当前不是 `.md` 笔记时，上面两条命令会自动置灰。

导出完成后会提示：落到哪、内联了几张、有没有找不到的。

## 设置

`设置` → `MD Base64`：

| 字段 | 说明 | 默认 |
| --- | --- | --- |
| **导出方式** | `浏览器下载` = 触发系统下载 / `写入库内文件夹` = 直接存到库里（手机更方便） | 浏览器下载 |
| **库内导出文件夹** | 仅"写入库内"模式显示。不存在会自动创建。文件名 = `原笔记名.base64.md` | `Exports` |
| **导出后自动打开** | 仅"写入库内"模式显示 | 关 |
| **也内联远程图片** | `![x](https://…)` 也下载内联。网络慢 / 图大时导出会久一点 | 关 |

## 支持的图片语法

```
![[图片.png]]
![[图片.png|300]]          ← 300 是宽度，用 <img width> 保住
![[图片.png|别名]]
![别名](图片.png)
![别名](<含 空格 的路径.png>)
![别名](图片.png "标题")
```

已经是 `data:` 的图片会自动跳过 → **可反复导出，不会二次膨胀**。

## 支持的图片格式

`png` / `jpg` / `jpeg` / `gif` / `webp` / `bmp` / `svg` / `avif` / `ico` / `tif` / `tiff`

要加格式：改 `main.js` 顶部的 `MIME` 表，加一行即可。

## 已知边界

1. **产物会变大**：base64 让图片体积膨胀约 **33%**（3MB 的图 → 4MB 文本）。base64 的物理特性，任何实现都一样。
2. **导出瞬间会忙一下**：图片多 / 大时，读图 + 编码要几百毫秒到几秒（一次性）。日常写作**零开销** —— 那段代码只在点导出时执行。
3. **找不到的图片保持原样**，并在提示里列出来。
4. **远程图片默认不内联**（要在设置里打开）。
5. **SVG 走 `image/svg+xml`** 内联；部分编辑器对 SVG 的 data URI 支持不好，属正常现象。
6. 写入库内模式下，同名 `*.base64.md` 会被**直接覆盖**（不生成副本）。

## 开发

```
MD-Base64/
├─ manifest.json      ← 清单（改版本号在这）
├─ main.js            ← 源码，未压缩、中文注释，直接改这个
├─ styles.css         ← 状态栏按钮样式
├─ versions.json      ← 发布用版本表
└─ tools/
   └─ _selftest.js    ← 自测台（32 项）
```

**改完两步**：① `manifest.json` 的 `version` 加 1；② 重载插件（设置 → 第三方插件 → MD Base64 关掉再打开）。

**自检**：

```bash
node tools/_selftest.js        # 32 项全过才算没改坏
node --check main.js           # 语法兜底
```

改了 `findRefs()` 的正则后，**务必**拿上面那 6 种语法都试一遍。
